# Beybao-sample

BEYBAO brand website: everyday bags by PT Shoca Harapan Sejahtera. *Made to carry your days.*

- `index.html`: the whole site (one page, no build step)
- `img/`: product photos

To change shop links or the WhatsApp number, edit the `LINKS` block near the top of the `<script>` in `index.html`.
